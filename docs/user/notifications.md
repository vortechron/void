# Agent completion alerts

Open **Settings → General → Notifications** to control alerts when an agent finishes a turn.

- **Agent notifications** shows a system notification for each completed turn. The first time you
  enable it, allow notification access in your browser or operating system. Selecting the
  notification opens the completed thread.
- **Completion sound** plays a short chime for a completed turn. Choose **None** to mute it, or use
  **Test** to preview the selected sound.

These preferences are stored on the current device and apply to completed turns from every
environment connected to that web or desktop client. Interrupted and failed turns do not alert.
